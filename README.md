# Step 1 Interativo

Curso interativo baseado em questões para o USMLE Step 1 — mecanismo antes do fato, testes o tempo todo e domínio medido por conceito.

**Site:** https://abiliosovai-wq.github.io/Abilio/

- Módulo piloto: Bioquímica → Metabolismo dos carboidratos (pré-teste e Unidade 1 prontos; demais unidades em construção).
- Funciona no celular e no tablet, instalável na tela inicial e offline.
- Progresso salvo no aparelho, com exportar/importar entre aparelhos.

Conteúdo original, escrito no estilo da prova. Regras de conteúdo e esquema de dados: [`CLAUDE.md`](CLAUDE.md) e [`docs/SCHEMA.md`](docs/SCHEMA.md). Plano pedagógico: [`docs/PLANO-PILOTO.md`](docs/PLANO-PILOTO.md).

Cada envio ao GitHub roda a validação do conteúdo (`scripts/validate.mjs`) e publica o site automaticamente pelo GitHub Actions.
